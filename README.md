# GitHub Image Lightbox

Öffnet Bilder in GitHub-Issues, Pull Requests, Kommentaren und READMEs in einer Lightbox direkt auf der Seite statt in einem neuen Tab.

- **Klick** auf ein Bild → Lightbox
- **Klick aufs Bild** in der Lightbox → Zoom auf Originalgröße (scrollbar), nochmal klicken → zurück
- **Esc**, **✕** oder Klick auf den Hintergrund → schließen
- **↗** → Original wie bisher in neuem Tab
- **Strg/Cmd/Shift-Klick** oder Mittelklick → normales Verhalten (neuer Tab)

Bilder, die bewusst auf eine andere Seite verlinken (z. B. Badges), werden nicht abgefangen.

## Installation (Chrome / Edge)

1. `chrome://extensions` bzw. `edge://extensions` öffnen
2. **Entwicklermodus** einschalten
3. **Entpackte Erweiterung laden** → diesen Ordner `github-image-lightbox` auswählen
